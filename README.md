# Pattern Clash

  A mobile-friendly pass-and-play memory pattern game for two players.

  ## How to Play

  1. Enter both player names and tap **Start Game**
  2. Player 1 taps a sequence of coloured buttons to create a pattern
  3. Tap **Lock Pattern** and hand the device to Player 2
  4. Player 2 must repeat the exact same sequence from memory
  5. Correct = Player 2 scores. Wrong = Player 1 scores. Roles swap each round.

  ## Stack

  React 19 + Vite 7 · Tailwind CSS v4 · shadcn/ui · wouter

  ## Development

  ```bash
  npm install
  npm run dev
  ```

  ## Deploy to Vercel

  - Framework: **Vite**
  - Build command: `npm run build`
  - Output directory: `dist`
  - No environment variables needed
